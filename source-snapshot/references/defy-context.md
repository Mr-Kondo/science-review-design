## 1. 最初に確認すること

1. `AGENTS.md`: プロジェクトの目的（ダークSFファンタジーの作成）。短い。
2. `README.md`: ファイル命名規則と参照規則。ここから**資料の優先度**と**種別**が分かる。
   - `P0` が最重要、`P9` が最も低い補足。`P`=設定、`C`=登場人物、`S`=シナリオ。
   - 人物番号 `00`=主人公、`01`=遠野舞歌、`02`=テオ、`03`=サポートAI（アル）、`09`=ニコラ・テスラ（会長）。
   - 設定ファイル本文が他ファイルを参照する場合、参照先は `P` で始まるファイルか `README.md` に限る。
   - 時系列の基準は `P0-P-00-01-kamenRiderDefy.md`「時系列の基準」節。
3. `CLAUDE.md` は存在しない（2026-10-08 時点）。プロジェクト固有のスキルも、このスキル以外にはない。

## 7. 便利な確認コマンド

```
git rev-parse --short HEAD ; git status --short <file>          # 作業ツリーの状態
stat -f '%Sm %N' -t '%Y-%m-%d %H:%M' <file>                      # 更新日時（macOS）
grep -n '^#' <file>                                              # 見出しと節名
grep -n '【確定】\|提供設定\|要確認\|要設定\|未確定' <file>        # 格の手がかり
grep -rn '<技術名>' --include='P[0-9]*.md' .                     # 関連箇所の探索
```
