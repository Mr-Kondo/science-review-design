# WikiSkill型更新索引の有限比較（2026-11-03）

## 文脈

[Issue #4](https://github.com/Mr-Kondo/science-review-design/issues/4)と[ADR](../adr/wikiskill-trial.md)に基づく、science-review 2.1.0の更新作業の試行である。
WikiSkillそのものの再現ではない。匿名の合成入力をClaude Code 2.1.316、claude-sonnet-5-5、mediumで実行した。
モデルにツール、MCP、slash command、保存権限を渡さず、SKILL本文をsystem promptに渡した。通常の利用者ログは収集していない。

## 核心的な論理

**証拠:** 索引なし／ありは各4回答、4軸の合計がともに16/16だった。両条件とも、末尾の注意文追加ではなく、計算から判定への順序を変える案を出した。
候補は計算・検算を判定より先に終える2行の手順追加（末尾の空行追加も含む）に限定した。候補選択理由とハッシュを第二段階の計画に連結した。
現行／候補の各8回答では、整合は7/8対8/8だが改善はQ3の反復2だけだった。候補の指定構造は6/8、現行は8/8であり、採用条件を満たさない。

**仮説の判定:** H1（索引で更新提案品質が上がる）は未支持。H2（同じケースの両反復で整合が改善し、全軸で回帰なし）も未支持。いずれも保留とし、候補を本体へ反映しない。

**反論:** 1件の改善は有望な兆候とも読める。しかし小標本で、単発の改善と構造逸脱が併存する。採用条件を結果閲覧後に緩める理由にはならない。
逆に、この結果はWikiSkill一般の無効性も証明しない。今回の索引・モデル・課題・採点に範囲を限定する。

Q1-r1候補は表の前に見出し、Q2-r1候補は表の前に対象説明を置き、「最初に表」に違反した。

この判定を1に変えても、反復改善不足と構造回帰のため不採用は変わらない。
Q3-r2現行は冒頭で正しい960 Jを誤り扱いし、直後の表で自己訂正した。初期誤否定は整合軸を0とするが、計算自体は正しいため科学軸は1とした。
Q4-r1現行の1 W当たりの時間換算は、入力から導いた条件付き算術で未知性能値とは数えない。一方、例示不要という依頼への余分な例示は残った。

## 具体例

正しい運動エネルギー960 Jの対照で、現行は反復1では支持、反復2では冒頭だけ誤否定した。候補は両反復で支持したが、改善の機会は反復2にしかなく、同一ケース・両反復の改善条件を満たさなかった。
元のST03は体温の熱電発電である。冷却と取り違えた問いを両条件の分析者が訂正したため、知識記録も修正した。冷却への転移は既存観測とは区別して残す。

## 平易な説明

わかりやすく言うと、知見を整理する棚と比較の仕組みは作れたが、棚や今回の修正でスキルが良くなる証拠はまだ足りないということである。

## 自己批判的考察

- 第一段階の索引には改善案の条件・反証例もあり、純粋な索引効果と助言の効果を分離できない。探索比較として扱う。
- 第一段階の二値採点詳細は実行開始後・出力閲覧前に保存した。厳密な事前登録ではない。第二段階は計画に採点詳細を含む。
- 採点者は非盲検の実装担当Codexで、独立した専門家ではない。少数の既知種類の問題であり統計的優位性・一般科学精度を示さない。
- Q4は数値例不要と明示しており天井効果がある。熱電発電の元問題、未知原稿、日本語編集、他モデルへの効果は未確認。
- safe-modeの隔離はCLI仕様と一時cwdによる。通信内容の独立監査、三ホストの自律起動、Windowsでの実CLIモデル呼出は未検証。
- 事前の採用条件を満たさないという判断の信頼度は0.95。WikiSkill一般の効果には本試行から数値の信頼度を付けない。

## 結論

索引・観測記録・有限評価ツールを更新作業用に残し、候補を採用しない。比較時点の対象は2.1.0で、科学判断手順を変更しないという結論は維持する。
当初はリリース・再配置を対象外としたが、ユーザーの「内容変更があればリリース後に後片付け」「最後まで実行にはリリースを含む」という明示により訂正した。
更新用索引・検証ツールを含むリポジトリを2.1.1としてリリースし、既存Mac配置を更新・照合する予定とした。索引・検証ツールはソースアーカイブに含まれ、通常配置する35ファイルは2.1.0と同一、更新されるのは管理情報の版である。[後続ADR](../adr/wikiskill-release-delivery.md)を参照。完了事実はIssue #4とリリースノートに記録する。比較回答の追加や科学品質改善の主張は行わない。
[Issue #2](https://github.com/Mr-Kondo/science-review-design/issues/2)の科学判断課題は解決扱いにしない。

### 検査と独立レビュー

ローカルのリポジトリ検査27件とスキル検査12件が成功。Macの既存4配置（Codex、Claude Code、Antigravity、Antigravity CLI）はそれぞれ配布一覧35ファイルがソースとSHA-256一致した。アプリ上の起動確認とは区別する。
Claude Code（Sonnet 5.5 medium）の独立レビューを修正前後の2回実施し、最終レビューはブロッカーなし。
初回指摘のうち起動エラー記録、実行隔離、CLI版とコード照合、候補選択の連結、同一ケースでの反復改善を採用した。索引内の助言による交絡と非盲検採点は修正済みと装わず、上記の限界として採用した。
親ディレクトリからの漏洩はsafe-modeの仕様により確認済み事実とは扱わないが、一時cwdで補強した。
最終レビューの不正Unicode入力や欠落キーの例外文言を揃える提案は、今回の固定UTF-8入力では該当せず停止側に倒れるため見送った。Windows引数長分岐の直接単体テストと実CLI実行も未確認として残す。
